本模块为配套前文AR视觉九键虚拟键盘的视觉手势鼠标系统，运行于Windows11平台，依托摄像头实时图像识别手部手势，实现无实体鼠标的全域光标控制。
基础手势姿态固定为右手兰花指姿态作为待机基准姿态；通过识别手指间咬合动作、手指相对位移、整只手空间移动，映射为鼠标移动、左键、右键、滚轮操作。
 
关键特性：程序预览窗口并非全屏，但光标可控制整个电脑屏幕区域，需要实现摄像头画面坐标 → 系统桌面全屏坐标的透视映射转换。
 
2 运行环境
 
1. 操作系统：Windows 11

2. 硬件：USB/内置摄像头

3. 依赖：手部关键点识别算法；系统底层模拟输入接口

4. 配套：可与AR九键虚拟键盘程序整合为同一套视觉交互套件
 
3 手势定义（右手兰花指基准姿态）
 
基准待机姿态：标准右手兰花指，手指自然张开，作为识别的初始判定条件；系统仅在识别到该基础手势后，才启用鼠标控制逻辑，避免误触发。
 
1. 鼠标移动
整只右手在摄像头画面内发生平移；将手部基准关键点坐标，经过坐标映射换算，驱动系统光标在整个桌面屏幕同步移动。

2. 鼠标左键按下
保持兰花指基础姿态，食指指尖扣向大拇指末端关节，识别咬合接触判定为左键按下；手指分离则左键释放。

3. 鼠标右键按下
保持兰花指基础姿态，中指指尖扣向大拇指末端关节，识别咬合接触判定为右键按下；手指分离则右键释放。

4. 鼠标滚轮上下滚动
拇指保持相对静止，中指以大拇指为参照做上下相对滑动；向上滑动映射滚轮上滚，向下滑动映射滚轮下滚；滑动距离控制滚动幅度。
 
4 核心技术需求
 
4.1 坐标映射（重点要求）
 
1. 程序预览窗口尺寸自由可调、不要求全屏；摄像头采集画面范围 ≠ 电脑屏幕范围。

2. 建立映射规则：摄像头画面有效操作区域 → Windows全屏桌面坐标映射。

3. 支持比例归一化：手部在摄像画面左边界，光标对应屏幕最左侧；手部在摄像画面右边界，光标对应屏幕最右侧；上下轴同理。

4. 增加平滑滤波，避免手部微小抖动造成光标剧烈漂移。
 
4.2 手势识别逻辑
 
1. 前置校验：只有识别出兰花指基准姿态，才激活鼠标控制模式；手势消失则暂停控制。

2. 动作优先级：

- 手指咬合动作（左键/右键）优先级高于滚轮滑动；

- 滚轮滑动识别优先于单纯光标移动。

3. 防抖判定：所有点击、滚轮动作增加持续帧阈值，瞬时接触不触发指令，过滤光影抖动造成误识别。
 
4.3 系统输入模拟
 
1. 输出标准Windows原生鼠标事件，全局生效，不受预览窗口限制；任意软件内均可使用。

2. 支持完整事件：鼠标移动、左键单击/长按、右键单击/长按、滚轮上下滚动。
 
5 工作流程
 
1. 程序启动，摄像头持续采集画面，手部关键点模型实时检测右手；

2. 检测到右手兰花指基准姿态 → 激活鼠标控制模式；

3. 追踪手部基准坐标，经过坐标投射换算，驱动桌面光标移动；

4. 识别手指动作：

- 食指触碰大拇指 → 模拟左键按下；松开 → 左键释放

- 中指触碰大拇指 → 模拟右键按下；松开 → 右键释放

- 中指相对大拇指上下位移 → 触发鼠标滚轮

5. 手部离开画面、兰花指姿态消失 → 暂停鼠标控制；

6. 光标操作作用于整个电脑全屏桌面，不受预览窗口大小约束。
 
6 非功能性需求
 
1. 光标移动平滑性：增加移动插值算法，降低手部抖动带来光标震颤；

2. 灵敏度可调：预留参数，支持调整光标移动增益、滚轮滚动幅度、点击判定灵敏度；

3. 姿态容错：允许兰花指存在小幅自然形变，不必严格标准姿态；

4. 低延迟：手势识别到光标响应延迟尽可能降低，保障操控手感。
 
7 设计约束
 
1. 仅针对右手手势识别，暂不支持左手；

2. 基准姿态固定兰花指，不支持自定义基础手势；

3. 预览窗口仅作为摄像头画面预览载体，操作区域不受窗口边界限制，依靠坐标映射实现全屏光标控制；

4. 不修改系统底层驱动，采用标准API模拟鼠标输入。
